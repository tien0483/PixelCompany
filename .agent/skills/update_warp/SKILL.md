# Update Warp Skill

Update WARP (Graphify + Cocoindex) for the last initialized target.

## Usage
/update_warp

## Implementation
**Windows (PowerShell - routes to isolated WSL):**
```powershell
powershell -ExecutionPolicy Bypass -File ./warp.ps1 update
```

**Linux / macOS / Native WSL Zsh:**
```bash
./warp.sh update
```

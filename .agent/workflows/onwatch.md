# Onwatch Workflow

Review AI API usage, status, and active plans before proceeding with development.

## Steps
1. Run `onwatch status` to check quotas.
2. Run `onwatch ui` to open the dashboard if detailed metrics are needed.
3. Run `onwatch plan` to review current architectural intentions.
4. Run `onwatch proceed` once the context is verified.

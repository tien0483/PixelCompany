# Template: Magazine Article

- Hero at the top: big title (text-5xl/6xl) + optional subtitle + author / reading-time / date metadata.
- Body: single column, max width about 700px, centered. Paragraphs `text-lg leading-relaxed text-neutral-700 dark:text-neutral-300`.
- H2 / H3 headings use a serif font so the body and the headings contrast visually.
- Blockquotes use a bold accent-coloured left border + italics.
- Code blocks: rounded corners + dark background + light text, showing a language label.
- List items use custom bullets (small squares / accent dots).
- Sections separated by `<hr>`, but styled as a small centered ornament.
- End with a simple "If you found this useful, feel free to share" action card.
